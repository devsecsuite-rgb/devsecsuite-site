Hi — I'm Emiliano. I build and maintain DevSecSuite, a set of free browser-based tools for developers and security engineers.

Why I built this

I built DevSecSuite because I got tired of pasting JWT tokens and API keys into random websites that quietly send your data to a server.

It happens constantly: you need to decode a JWT, generate a password hash, format a SQL query, or check a Base64 string. You search Google, click the first result, and paste your data in. You have no idea what that site does with it. Most of them send your input to a server — sometimes to log it, sometimes to "analyze" it, sometimes to sell it.

For anyone handling API keys, JWT tokens, production queries, or password material, that's a real risk. And most of the time, you don't need a server at all. The browser can do the work locally in milliseconds.

So I built DevSecSuite. Every tool runs entirely client-side. Nothing you type, paste, or upload ever leaves your machine. You can verify this yourself in 30 seconds — the How It Works page shows you exactly how.

What I care about

  • Privacy by architecture, not by promise. There is no backend. There is nothing to trust.
  • Standard tools, standard specs. Every tool uses documented standards (RFC 4648, RFC 7519, Web Crypto API) so you can verify outputs against your own command line.
  • No accounts, no signup, no tracking of your input. The tools are free and always will be.
  • One tool, one job. No bloat, no forced "sign up to see results," no dark patterns.

What's on the site

Currently 18 tools covering the most common developer and security tasks: encoders and decoders, formatters, hash and password generators, JWT decoding, regex testing, and more. New tools get added as I find gaps.

See the full list on the homepage.

How the site is funded

DevSecSuite runs on Cloudflare Pages (free tier) with no server costs. If the site grows, I may add lightweight, privacy-respecting ads to cover hosting. Nothing about the tools would change — no data is ever sent anywhere, ads or not.
