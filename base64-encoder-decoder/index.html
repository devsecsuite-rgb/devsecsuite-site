Base64 Encoder / Decoder

Encode text to Base64 or decode Base64 back to text. Everything runs in your browser — no data is sent to a server.

What Is Base64?

Base64 is a binary-to-text encoding scheme that represents binary data using 64 printable ASCII characters (A–Z, a–z, 0–9, +, /). It's used when binary data needs to be transmitted over media designed for text, like email, JSON, or URLs.

Common Uses

Email Attachments

MIME email encodes attachments as Base64 because email protocols are text-based. A PDF attachment, for example, is Base64-encoded before sending.

Data URIs

Small images can be embedded directly in HTML or CSS using Base64 data URIs. This avoids extra HTTP requests but increases file size by about 33%.

API Authentication

HTTP Basic Auth encodes credentials as Base64. JWT tokens also use Base64URL encoding for their header and payload sections.

Frequently Asked Questions

Is Base64 encryption?

No. Base64 is encoding, not encryption. Anyone can decode it instantly. Never use Base64 to protect sensitive data.

Why does Base64 make my data bigger?

Base64 uses 4 characters to represent every 3 bytes of original data. This is a 33% size increase. The trade-off is that the encoded output is safe to transmit over text-only channels.

What's Base64URL?

Base64URL is a variant that replaces + with - and / with _, and omits padding. It's safe for use in URLs and filenames. JWTs use Base64URL.

Do you store my data?

No. Everything runs in your browser. Nothing is sent to our servers.
