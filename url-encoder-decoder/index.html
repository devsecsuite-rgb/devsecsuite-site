URL Encoder / Decoder

Encode or decode URLs and query strings using percent-encoding. Everything runs in your browser.

What Is URL Encoding?

URL encoding (also called percent-encoding) converts characters that aren't safe for URLs into a %XX format, where XX is the hexadecimal byte value. Spaces become %20, ampersands become %26, and so on.

encodeURI vs encodeURIComponent

encodeURI

Encodes a full URL. Does not encode characters that are valid anywhere in a URL, like :, /, ?, #, &. Use when encoding a complete URL.

encodeURIComponent

Encodes a single component of a URL, like a query parameter value. Encodes more characters, including :, /, ?, &. Use when encoding a parameter value that will be inserted into a URL.

Frequently Asked Questions

When do I use which?

Use encodeURI when your whole string is a URL you want to keep intact. Use encodeURIComponent when you're building a query string or path segment from user input — this prevents injection of & or = characters.

Why does my URL break with spaces?

Spaces are technically not allowed in URLs. They get encoded as %20 (or + in query strings). This tool uses %20.

Do you log my URLs?

No. Everything runs in your browser. Nothing is sent to our servers.
