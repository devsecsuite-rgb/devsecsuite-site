What Is JSON?

JSON (JavaScript Object Notation) is a lightweight data interchange format. It's readable by humans and machines, and it's the standard format for APIs, configuration files, and data storage in modern web development.

When to Format vs Minify

Format (Pretty Print)

Adds indentation and line breaks to make JSON readable. Use for debugging, reviewing API responses, or editing config files. Increases file size but improves readability.

Minify

Removes all whitespace to reduce file size. Use for production APIs, network transmission, and storage. A 10KB formatted JSON file might shrink to 6KB minified.

Frequently Asked Questions

Why does my JSON fail to parse?

Common causes: trailing commas (not allowed in JSON), single quotes instead of double quotes, unquoted keys, comments (not allowed in JSON). This tool reports the exact line and column of the error.

Is JSON the same as JavaScript objects?

Similar but not identical. JSON requires double quotes around keys and string values. JavaScript objects allow single quotes, unquoted keys, and functions. JSON is a subset of JavaScript literal syntax.

What's JSON5 or JSONC?

Extensions that allow comments and trailing commas. Used in config files (like VS Code settings). Not valid JSON — most parsers will reject them.

Do you store my JSON?

No. Parsing happens entirely in your browser. Nothing is sent to our servers.
